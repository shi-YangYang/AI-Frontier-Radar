# Specs Directory

This directory is the home for V1.1 and later feature specs.

Use one directory per feature:

```text
docs/specs/v1-1-001-short-name/
```

Each feature must follow the harness defined in:

```text
docs/harness/README.md
```

Do not start implementation until the feature has at least:

- `00-intake.md`
- `01-spec.md`
- `02-design.md`
- `03-implementation-plan.md`
- task prompts under `tasks/`

V1 documents under `docs/sdd` remain historical source material. New specs should reference them when useful, but should not continue adding ad-hoc batch files under `docs/implementation`.
