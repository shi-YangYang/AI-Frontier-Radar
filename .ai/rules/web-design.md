# 网页内容与信息设计规范

适用于面向真实用户的网页和 Web 前端界面。设计应服务于用户理解信息、作出决策和完成操作，而不是解释产品或技术实现。

## 基本规则

1. **精简内容**：只保留必要信息，删除冗余描述、解释性小字和重复内容；不要为填充页面而添加文案，也不要习惯性地为每个模块添加副标题或说明。
2. **面向用户**：只展示用户实际需要的信息、状态和操作；禁止将开发说明、技术实现、设计意图或 AI 自我解释写进用户界面，避免空洞的营销话术。
3. **统一语言**：中文网页统一使用简体中文；除品牌名、专有名词及必要技术术语外，不随意中英文混用。同一概念的称呼应保持一致。
4. **优化信息呈现**：控制信息密度，突出主要内容与关键操作；通过清晰的布局、留白、视觉层级和交互传达信息，不依赖大段文字解释，避免无意义的装饰和信息堆叠。
5. **保证可用性**：按钮与操作名称应清楚直接；重要状态、错误信息、操作风险及限制必须明确呈现，不得为了简洁而隐藏必要提示。保持页面在不同屏幕尺寸下易读、易操作。

## 检查标准

逐项检查用户可见内容：用户真的需要看到吗？能否缩短或删除？是否在解释内部实现？有无不必要的中英文混用？关键操作与必要提示是否清晰？

**最终要求：界面简洁、自然、直观，优先展示信息与操作，而非描述界面本身。**
