# Spec

## 背景

用户端只有微信绑定配置；用户想查看消息只能进管理端。绑定流程也没有说明「必须发一条消息」，且微信 24 小时/10 条额度对用户不可见。

## 目标

1. 用户端改为双页签：**消息**（浏览全部消息）+ **微信推送**（原配置）。
2. 绑定流程引导：扫码前说明需发消息；绑定后未激活时轮询检测并提示；激活后明确显示「可以接收」。
3. 额度可视化：进度条 + 「已推送 n/10 条」+ 重置说明。
4. 微信消息底部附加 `当前消息[n/10]`，达到上限时附加容量已满提示。

## 非目标

- 消息页签不做筛选/搜索（管理端已有完整筛选）。
- 不改变管理端消息页。

## 验收标准

- [ ] 用户端可浏览消息（分页、来源、标题/正文、原文链接），接口需登录
- [ ] 绑定页显示会话状态与额度进度
- [ ] 桥发送带 tip 与计数，用户发消息后计数重置
- [ ] smoke/typecheck/build 通过
