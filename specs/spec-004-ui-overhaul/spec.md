# Spec

## 背景

用户反馈：管理台 UI 排版乱；信息展示过细（时间、发帖人等 tag 堆砌），用户真正在意的是内容本身。本轮基于 11 张全页面截图逐页分析，参考成熟产品（PatternFly 仪表盘指南、卡片设计规范、AI 资讯聚合站实践）重排布局与信息密度。

**截图证据**（`.tmp/ui-shots/`）：

- 总览：5 张全零指标卡 + 三个超大入口卡片 + 大片空白。
- 消息内容：筛选区常驻 8 控件占半屏；每张卡片 4 个元数据块（北京时间/UTC/检测时间/帖子 ID）+ 5 个投递 chips（多为 0）。
- 监听源：组合说明是一大段长文本；表格含「基线帖子/最新帖子」内部 ID 列；空数据仍渲染表头与分页。
- 最近轮询/最近发送：空数据渲染完整表头 + 「第 1/0 页，共 0 条」；删除按钮是重红色块。
- 设置：6 个 tab 做成大卡片占两行；技术列（targetKey/创建/更新时间）；中英混排（source mode / browser base URL / proxy override）。

## 目标

1. 统一布局系统与视觉层级，消除“卡片堆叠 + 空白失衡”。
2. 按“内容优先”压缩信息密度：每个视图只保留支持一个决策的信息。
3. 覆盖完整状态：有数据、空、加载中、错误；空状态不再渲染表头与分页。
4. 统一语言与术语（中文界面为主，技术名保留必要英文）。

## 非目标

- 不改动后端 API、数据结构与业务逻辑（仅前端展示层）。
- 不引入 UI 组件库或新依赖。
- 不重做品牌与图标体系（现有 Logo/导航图标保留）。

## 设计基线（参考成熟实践）

- 侧边栏 240-280px；内容区限制最大宽度（如 1280px）居中，避免超宽拉伸。
- 12 列网格、8px 间距节奏；卡片统一圆角 12px、内边距 20px、无重阴影（PatternFly / 卡片设计规范）。
- KPI 条 ≤ 4 张卡，每卡一个指标；只保留能驱动决策的指标（“自动刷新状态”这类不是指标）。
- 卡片只承载支持一个决策的信息，其余移入详情（drawer）；正文 14-16px，不用小字号硬塞。
- 状态设计：空/加载/错误必须显式设计（Superdesign：AI 生成界面通常只做“好看的成功态”）。
- 层次：一个页面一个主操作；危险操作弱化（文字按钮/图标），删除确认保留。

## 目标行为（按页）

### 总览

- KPI 精简为 4 张：监听源（启用/总数）、今日新帖、待发送、最近轮询（状态 + 相对时间）。
- 移除三个超大入口卡片；「管理监听源/查看轮询/查看发送」改为 KPI 卡片内链接或页头次级操作。
- **新增「最新消息」模块**：展示最近 5 条（来源徽标 + 标题/摘要 + 相对时间 + 打开原文），数据复用 `/admin/api/posts`。
- 「最近轮询」面板精简为：状态、时间、账号结果、新帖数（去掉结束时间等冗余；更多见 `/poll-runs`）。

### 消息内容（重点）

- 筛选区默认收起为一行：关键词 + 快捷时间（今天/近 7 天/近 30 天/全部）+「更多筛选」；展开后才是作者、时间范围、类型。
- 卡片信息层级改为：**来源徽标 + 作者名 + 相对时间 → 正文（3 行截断）→ 打开原文**。
- 移除卡片上：UTC 时间、检测时间、帖子 ID、5 个投递状态 chips。
- 投递状态仅在详情抽屉展示；“有失败/死信”时卡片上给一个小红点提示。
- 指标卡保留：全部消息、今日新增、最近更新（移除“自动刷新状态”卡，刷新按钮保留在页头）。
- 时间显示为相对时间（“2 小时前”），hover/详情显示完整北京时间。

### 监听源

- 组合说明精简为一句概述 + 「查看包含的源」折叠；面板与表格间距收紧。
- 表格列精简：来源（徽标 + 名称/URL）、类型、最近轮询（相对时间）、状态、操作；移除基线/最新帖子 ID 列。
- 空状态改为友好面板（含“从监听组合一键添加”的行动指引），不渲染表头与分页。

### 最近轮询 / 最近发送

- 空状态改为友好面板；有数据时才渲染表头与分页。
- 轮询列精简：开始时间（相对 + 完整时间 tooltip）、状态、结果（x/y 成功）、新帖、待发送、操作；删除按钮弱化。
- 发送列精简：时间、帖子（标题/作者摘要，不再是 ID）、目标、状态、尝试、操作。

### 设置

- 6 个 tab 改为一行紧凑 tab bar（保留下方一行描述，可横向滚动），不再用大卡片。
- 飞书列表列精简：名称、状态、脱敏预览、操作（移除 targetKey/更新时间）。
- 术语统一：source mode → 数据源模式；browser base URL → 浏览器入口；proxy override → 代理覆盖；profile 目录 → 浏览器档案目录。
- 长值（路径、配置摘要）截断显示 + 复制按钮；X 配置摘要拆分展示。
- 「当前来源：SQLite 覆盖」在轮询配置中重复出现 → 收敛为表单底部一行说明。
- 空列表统一使用空状态面板。

## 功能需求

1. 新增共享空状态组件（标题 + 说明 + 可选操作按钮），全站替换表格空态。
2. 新增相对时间工具函数（北京时间完整时间作为 tooltip/详情）。
3. 按上述逐页调整模板与样式；不改变既有数据获取与交互语义。
4. 总览新增「最新消息」模块（只读）。
5. 保留中英双语与现有测试通过。

## 边界条件

- 空数据（0 源 / 0 帖 / 0 事件）时页面不出现表头、分页与 0 值指标卡堆积。
- 超长标题/正文/URL 截断或换行，不撑破布局。
- 移动断点（≤920 / ≤680）下筛选区、卡片、tab bar 正常折叠。

## 技术约束

- 仅改动 `web/admin`（Vue 模板 + styles.css + i18n + utils）；必要的新增前端只读调用。
- 不新增依赖；沿用现有 design tokens（可微调）。
- 不破坏既有 `data-testid` 类选择器用途（若截图中涉及自动化）。

## 验收标准

- [ ] 11 张页面截图（含设置 6 个 tab）与新设计一致，且无信息堆砌项（UTC/检测时间/帖子 ID/targetKey 等不再出现在列表卡片上）
- [ ] 空状态截图：监听源、轮询、发送、帖子筛选无结果均为友好空面板，无表头/分页
- [ ] 总览含「最新消息」模块且数据正确
- [ ] 消息卡只保留：来源徽标、作者、相对时间、正文摘要、原文链接；详情抽屉保留完整元数据
- [ ] 设置页为紧凑 tab bar，术语统一
- [ ] `npm run typecheck` / `npm run build` / `npm run smoke:e2e` 通过
- [ ] 中英文案均更新
