# 管理员端设计依据与实施规范

## 现状诊断

- 监听源页在主列表前永久铺开推荐组合和新增表单，出现多个同等显眼的主按钮；只有一条数据时，列表仍占满巨大白面板。
- 设置页小数字输入横跨大卡片，页标题和卡片标题重复，部分区域缺少独立的阅读宽度。
- 颜色主要依赖浅灰边框和重复靛紫，导航/内容/动作的区别不充分；字号和控件偏小，长说明占据视觉中心。
- 截图旧脚本只捕获视口内的内部滚动区，不能作为长设置页已检查的证据。当前真实消息量较少，不能用空态代替有数据状态的验证。

上述资料没有规定本项目必须采用某种配色或固定尺寸。以下数值和深色导航均为本项目设计选择。旧文档中关于 Vercel 纯黑白/全无阴影、Stripe 固定4px圆角、禁止一切斑马纹等未获证实的断言不再使用。

## 视觉方向

**深蓝灰导航 + 浅色工作区 + 青绿强调。** 呼应现有雷达品牌，利用明暗区分稳定导航与日常工作内容。内容区保持明亮、清晰，避免大面积渐变、装饰图案或无数据支撑的图表。

颜色语义在管理员、登录和用户页之间统一；各自的布局限定作用域。必要 Teleport 弹层应能继承对应页面主题，不能出现混杂的紫色控件。登录采用深蓝灰品牌区与浅色表单，用户页采用深蓝灰顶栏与明亮阅读区，不引入管理员侧栏。

登录品牌区保留雷达扫描作为视觉特征。[Inspira UI Ripple](https://inspira-ui.com/docs/cn/components/backgrounds/ripple) 提供同心圆背景动效参考，[Motion for Vue](https://motion.dev/docs/vue) 支持 Vue 旋转等动画；当前需求沿用项目现有 CSS 同心圆、锥形渐变与旋转关键帧即可，不新增运行时依赖。雷达是装饰元素，位于文案下层、不响应指针；减少动态效果偏好下保留静态图形。

选定主按钮白字对比度约5.47:1，导航主文字约10.94:1、辅助文字约7.32:1；辅助正文在浅画布上约4.94:1，输入边界与白底约3.18:1。这是颜色对计算，不代表完整无障碍审计。

字体沿用本地系统中文字体。页面标题24px/32px、分区标题16px/24px、正文14px/22px、说明13px/20px；数字使用 tabular-nums。间距采用4/8/12/16/24/32，默认控件36px、行内操作32px，圆角控件8px/面板12px。焦点使用2px实色轮廓与适当offset，不只依靠半透明光晕。

## 布局与组件规则

- 导航宽约224–232px；品牌、工作区导航、管理导航、账户分别成组。保留已有图标和路由。设置九个子项需能滚动访问，账户区不覆盖导航。
- 顶栏约56px，面包屑准确包含设置当前子页；右侧语言切换。正文四周24–32px，最大宽度约1440px；设置正文约1100px。
- 页头上下有明确留白，主要动作最多一个实色按钮；刷新、查询/清空等次要动作白底或轻底；危险动作不能和主操作抢权重。
- 普通数据表自然高度并设合理最小内容区，不为一条记录填充整屏白面板。需要密集滚动时使用局部区域，并保证分页、表头、动作能访问。
- 空态含克制的线性图形、明确标题与简短说明；有现成下一步时给路由入口。加载失败沿用真实错误提示，不呈现虚构健康状态。
- 设置分区使用“简短说明 + 有阅读宽度的内容”，桌面可左右布局，窄屏上下；短数字输入180–220px，普通字段约400–560px，URL适当更宽。
- 高级配置、添加表单、推荐组合按需展开，不能删除功能或强迫进入新的路由。
- 统一状态标签、表格/列表操作和分页；只在选中记录后强调批量删除；清空历史仍可发现。

## 逐页结构

| 页面 | 目标 |
| --- | --- |
| 总览 | 指标一排，消息为主、运行状态为辅；运行参数用紧凑键值，避免同一信息反复占据多个大卡片 |
| 监听源 | 页头添加按钮 → 默认列表与搜索 → 紧凑推荐组合入口；新增表单和组合内容展开后完整可用；类型/源名/显示名同排，删除操作左对齐 |
| 消息 | 搜索/日期快捷项合为同一区；高级筛选展开；统计/导出轻量化；内容以有标题与摘要的阅读列表展现，保留详情 |
| 最近轮询 / 最近发送 | 日期筛选贴表格；有数据状态展示列头/行状态；批量选择后再强调操作；删除保留确认 |
| 日志 | 级别、自动刷新与缓冲计数统一工具栏；仅日志表体滚动，滚动条从表头下方开始，页头/工具栏/表头不随日志移动；长日志换行 |
| 投递通道 / 用户 | 已有列表优先，新增为独立可展开区域；URL/密码等字段保留明确标签 |
| 轮询配置 | 频率与抓取量短字段、过滤选项成组、局部保存 |
| X / RSS 源 | 当前摘要、代理配置、诊断清楚分区，长路径可换行；页面自然滚动 |
| 订阅规则 | 规则列表与新增规则分区；包含词/排除词和目标通道有清楚标签 |
| 微信 | 连接状态、账号列表和绑定操作区分；保留未登录/离线的真实状态 |
| 数据与备份 | 保留策略与备份各自成组；清理等危险动作和普通保存区分 |
| 运行信息 | 清晰键值表，长路径可换行，技术字段使用等宽字体 |
| 登录 | 深蓝灰品牌介绍保留原有同心圆雷达、缓慢扫光与轻网格，以青绿光色呼应品牌；有明确标签的限宽表单；手机压缩品牌区，登录及错误提示保持完整可见；减少动态效果偏好下显示静态雷达 |
| 用户微信 | 顶栏身份与退出、二级标签导航、连接状态与主动作、额度与订阅偏好分区；不凭空添加状态或指标 |
| 用户消息 | 搜索贴近内容、消息来源与时间清晰对齐、正文有可读行宽；保留展开、原文链接与加载更多 |

## 验证与证据

双桌面尺寸下逐页看 before/after，而不是仅检查截图数量。当前真实数据只作为真实现状；有数据、长内容和分页可用明确标注的浏览器 fixtures 补查。补查英文、窄屏、login/portal 以及展开表单/选择器/详情弹层。验收摘要说明实际覆盖和限制，完成验收后清理截图及临时验证产物。
